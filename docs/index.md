# Clover-Seq

**Clover-Seq** is a modular Snakemake pipeline for tRNA and small RNA sequencing analysis, developed by the Dartmouth Genomic Data Science Core.

## Overview

Clover-Seq provides workflows for:

- Building custom tRNA reference databases
- Preprocessing and aligning small RNA reads
- Quantifying tRNA expression and fragment profiles
